# Personal Dotfiles and Install Script


### Dependencies
- Arch Linux minimal install

### Installing

```git clone https://github.com/MrJuizy/dotfiles-and-install-script/```

```cd dotfiles-and-install-script```

```chmod +x install.sh```

```./install.sh```
